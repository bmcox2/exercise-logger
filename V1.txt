Exercise Logger V1

V1 Includes:
- Create a workout
- Add exercises to a workout
- Display a workout
- Create multiple workouts in one run
- View all workouts
- Save workouts to a file
- Load workouts from a file

V1 Does Not Include:
- Editing workouts
- Deleting workouts
- Muscle group analysis
- PR tracking
- Stats/charts
- GUI
- Database
- Accounts/login


Build Order:
1. Single workout from user input
2. Multiple exercises in one workout
3. Multiple workouts stored in memory
4. Simple menu
5. Save/load from file
6. Cleanup and polish

Phases:

Phase 1:
- Create one workout
- Add exercises
- Display workout

Phase 2:
- Replace hardcoded values with user input

Phase 3:
- Let one workout contain multiple exercises

Phase 4:
- Store multiple workouts in a vector
- View all workouts

Phase 5:
- Save workouts to json file
- Load workouts on startup

Phase 6:
- Clean up formatting
- Improve naming/output
- Update README

V1 Complete When:
- User can create multiple workouts
- Each workout can contain multiple exercises
- User can view all workouts
- Workouts persist after closing and reopening program
